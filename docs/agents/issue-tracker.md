# Issue tracker: GitHub

Issues and specs live in `pulkitv52/AI_service_desk_copilot`.
Use the `gh` CLI for issue operations.

- Publish specs and implementation tickets as GitHub issues.
- Read the relevant issue and comments before working.
- Use `--body-file` for multiline issue bodies and comments.
- Link implementation issues to their parent spec.
- Use native issue dependencies where available; otherwise record
  `Blocked by: #<number>` in the issue body.

PRs as a request surface: no.
