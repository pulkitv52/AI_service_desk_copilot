# AI Service Desk

## Language

**Support issue**:
One employee problem being investigated or escalated.

**Conversation**:
The saved exchange about one support issue. A new issue starts a separate conversation.
_Avoid_: Session when referring to the support issue's lifecycle.

**Incident**:
A ServiceNow record for an interruption or degradation of an IT service.
_Avoid_: Service request when reporting a fault.

**Service request**:
A request for software, access, or another standard service, potentially requiring approval.
_Avoid_: Incident when requesting new software.

**Escalation acceptance**:
An employee's explicit instruction to create an incident for the current support issue.

**Pending verification**:
An escalation whose external outcome is uncertain. Another creation attempt is blocked while that uncertainty remains.

**Reconciliation**:
Checking ServiceNow for the incident associated with a saved escalation and recording its confirmed identity locally.
